1아이폰 (홈 화면 앱)

새 판은 앱을 닫았다 열면 들어와요. 처음 한 번은 옛 화면이 나올 수 있어서 1~2번 합니다.

  1. 화면 맨 아래를 위로 쓸어 올리다 중간에 멈추면 열린 앱들이 카드로 보여요.
  2. JB's 캘린더 카드를 위로 휙 밀어 닫습니다.
  3. 홈 화면 아이콘을 눌러 다시 엽니다.
  4. 한 번 더 1~3번을 합니다. 이제 최신판이에요.
그래도 안 바뀌면
  1. 맨 위 「캘린더 열기」를 눌러 사파리로 엽니다.
  2. 주소창의 새로고침(↻)을 한 번 누르고 잠깐 기다립니다.
  3. 사파리를 닫고, 홈 화면 앱을 다시 엽니다(닫고 열기 1~2번).
마지막 방법 — 앱을 지우고 다시 추가
  1. 홈 화면의 JB's 캘린더 아이콘을 꾹 눌러 → 앱 제거 → 삭제.
  2. 맨 위 「캘린더 열기」로 사파리에서 엽니다.
  3. 아래 공유 버튼(네모에 위 화살표) → 홈 화면에 추가 → 추가.
    공유 버튼이 안 보이면 주소창 옆 ⋯ 안에 있어요.
  4. 새 아이콘으로 열고, 구글 연결을 물으면 본인 계정으로 다시 연결합니다.

✅ 일정·할 일은 구글 캘린더에 저장돼 있어서 앱을 지워도 지워지지 않아요.

2PC (크롬·엣지)

캘린더 화면을 띄운 채로 아래 키를 한꺼번에 누르세요. 최신판을 새로 받아요.

  • 윈도우: Ctrl + Shift + R
  • 맥: Cmd + Shift + R

설치한 앱 창(바탕 화면 아이콘)으로 쓰셔도 같은 키로 됩니다.

3v15 새 기능

바로 됨 그냥 쓰면 돼요. 구글 허용 처음 한 번 허용이 필요해요(아래 4번).

  • 🎥일정에 Zoom·Teams 회의 링크가 있으면 목록에 Zoom 참가 같은 버튼이 생겨요. 바로 됨
  • 🚗일정 편집에서 장소 아래 이동 시간 계산 → 차로 몇 분 걸리는지와 카카오맵·네이버 지도 길찾기. 바로 됨
  • 🔔☰ → 이 기기 알림 켜기 → 아이폰이 알림을 물으면 허용. 앱이 열려 있을 때만 울려요. 바로 됨
  • 🕒일정 편집에서 가용 시간 확인 → 나와 참석자가 모두 비는 시간을 찾아 줘요. 구글 허용
  • 📎＋ 파일 올리기(구글 드라이브)로 일정에 파일 첨부, 참석자 칸에 이름만 쳐도 연락처에서 찾아요. 구글 허용

4처음 쓸 때 「허용」

위 구글 허용 기능을 처음 누를 때 한 번만 나와요.

  1. 「… 구글 권한 추가」 창이 뜨면 허용하러 가기.
  2. 구글 화면에서 본인 계정이 맞는지 보고 고릅니다.
  3. 「확인되지 않은 앱」 경고가 나오면 고급 → 아래 「…(으)로 이동」을 누릅니다.
    가족끼리 쓰려고 직접 만든 앱이라 나오는 안내예요.
  4. 체크 상자가 있으면 체크하고 계속.
  5. 앱으로 돌아오면 「‘…’ 권한을 허용했습니다」가 잠깐 보이고, 하던 일정 편집 창이 다시 열려요.
허용하지 않아도 기존 일정·할 일은 그대로 쓸 수 있어요. 그 기능만 안 될 뿐이에요.
